## Additional v0.9A audit gates — 1 November 2026

Read the consolidated `docs/SOURCE_AUDIT_DECISION_REGISTER_2026-11-01.md` and two targeted investigations, `docs/SOURCE_AUDIT_FRAMEBUFFER_GEOMETRY_2026-11-01.md` and `docs/SOURCE_AUDIT_RENDER_SCALER_GUI_BOUNDS_2026-11-01.md`, before any interface/artwork changes.

**Source constraints now established:**
- Original mission output is 640×400 at output **rows 40–439**, and mission logical mouse Y subtracts 40. Incorrectly treating the whole 640×480 window as map coordinates would break click and edge scrolling.
- Existing menu text generation uses an 800-pointer table but may overflow if 267 or more input strings are supplied; do not add/expand `guitext.dat` without resolving/testing the data contract.
- Existing SDL software conversion contains a fixed 4-byte pixel write even for supported 16-/24-bit formats in its scaled path, and ignores surface row pitch. These **preexisting conditional source issues are not a demonstrated v0.7 gameplay failure**.
- Actual in-game menu/title facelift is **still unimplemented**. No gameplay source changes, build or playtest performed by the forensic audit. Window title edit remains the only preexisting v0.9A code change.

**Next approved development gate remains unchanged:** inspect original UI graphics/text files privately when available; isolate menu draw/pointer paths, compile a versioned branch and test all mouse, language, mode, alt-tab, scrolling, audio and mission flows. Do not assume a source audit alone establishes new visual functionality.
