## Exact control flow
- LoadSaveGame begins at assembly line 30354, with local byte at 0x4(%esp) zeroed at line 30366. The 13-entry event jump table at 30337–30350 dispatches 0..9 to slot selection, 10 to cancellation, 11 to load, 12 to save. The dispatch checks the icon index <= 12 at 30589–30594.
- Slot handler func_27221 at 30597–30611 records the selected slot (savegame_slot) without setting the exit byte.
- Cancellation handler func_27255 at 30614–30618 sets 0x4(%esp)=1 and clears EBP, then branches to the shared redraw/exit stage. It makes no load/save API call.
- Load handler func_2725f at 30621–30631 validates savegame_slot < 10, calls ac_load_player at 30627, then unconditionally sets 0x4(%esp)=1. Native load_player is void and cannot report success to its assembly caller. For invalid slot >=10, the handler skips to jump_272a6 without setting that exit byte; an invalid slot should not be claimed to produce the normal exit path from this block.
- Save handler func_27280 at 30634–30646 validates slot < 10, calls ac_save_player at 30643, then unconditionally sets exit byte=1, ignoring native TbBool return value. Invalid >=10 slot similarly skips without setting the exit flag here.
- Shared stage def_27219 at 30651–30672 performs mouse/screen swap/input update then checks the exit byte: if zero, jumps back to menu loop jump_26fa4; if nonzero, falls through jump_272c7 at 30673 to clear transient 10-slot selection data, prepare the closing animation, and return (30677–30720).
- The return register receives EBP at 30714; the examined cancel and load paths set EBP=0, and save path jumps via jump_272a6 which also sets EBP=0. No reliable success status is established by that return for these operations. The source confirms exit behavior; the exact downstream UI effects beyond this function require separate caller inspection.

## Implications for campaign save isolation
The existing single completion byte conflates cancel, requested load completion and requested save completion. Failure of an opened/read save or a write is not represented by this flag. A future save subsystem needs distinct operation outcome reporting while retaining the legacy menu operation order, original successful-save credit rule and 10-slot behavior. Mode-specific namespace selection must occur before slot enumeration. Preserve Original Campaign, American Revolt, World Domination and isolated Custom Campaigns; do not guess filename conventions.
