## State 6: menu Exit
- Main menu click handler at lines 54467–54490 turns a vertical mouse click into a row index using (MouseY-0x5a)/0x22; when the calculated index is 5, line 54490 assigns state 6. Valid hit testing spans the interval >0x7c and <0x126 on this path. The UI text lookup uses gui_strings_p663 and language (lines 54456–54460); the exact displayed label has not been verified against retail language assets.
- The menu key handler at lines 54517–54534 maps the relevant keyboard shortcut value 5 to state 6. The separate F10 path explicitly sets state 6 at lines 54382–54385.
- The main loop checks 0x4(%esp)==6 at lines 54375–54377 and jumps to menu cleanup. Cleanup sets 0xc(%esp)=1 only for state 6 at 54713–54715; this byte is returned via AL at 54851, which syndicate() tests at lines 206–208 to take the early return.
- This establishes state 6 as the current exit-control code. Do not reuse for custom modes.

## State 10: map_selection transition
- func_37b29 at lines 54593–54627 invokes map_selection (54597), stores its returned EAX to the menu local 0x4(%esp) at 54603 (accounting for the preceding push), and branches to common menu dispatch.
- The caller explicitly compares the map_selection result against 9 and 10 at lines 54616–54619. Either leads to load_text for current_levno (54620–54626), then rejoins the main menu; other values return directly to the shared state handler.
- Menu state 10 triggers a separate cleanup transition at 54369–54372 and 54710–54711. Unlike state 6, the cleanup condition at 54713–54715 does not set the exit byte when the state is 10.
- The *meaning inside map_selection* of returned values 9 versus 10 is not established in this audit; do not label either 'mission successful' or 'campaign mode' without tracing map_selection itself.

- Keep independent state for campaign identity; preserve Original Campaign, American Revolt and future separate custom saves. Do not modify classic menu codes or v0.7 before runtime compatibility tests.
