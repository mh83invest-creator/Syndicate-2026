- Speed changes using bracket keys not perceptible.
- Scrolling toward the top pulls left; **new in v0.8**.
- Windows desktop unexpectedly appears while game remains running and restorable through taskbar; **new in v0.8**. No evidence of process termination/crash.
- User explicitly confirmed both regressions absent from v0.7.

## Actual changes in this experiment
Replaced the exact following feature-branch file blobs with the matching v0.7 `main` blobs:
- `engine/src/syndre.sx`: v0.7 edge/corner camera and original native ASM `scroll` call sites.
- `engine/src/game.c`: v0.7 game timing and SDL handling; remove experimental keyboard speed polling and persistence.
- `engine/src/game.h`: remove experimental camera control export.
- `engine/conf/wrappers_game.conf`: remove experimental assembly/C ABI wrapper.

These restore the precisely compiled v0.7 behaviour. **There is no adjustable scroll-speed feature in this control build.** This is intentional; do not describe it as a finished slider or new speed controller.
