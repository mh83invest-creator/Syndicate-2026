## Verified direct exits and launch gates
- map_selection begins at assembly line 31709, loads mmapblk resources via ac_LbDataLoadAll and renders territory/city info.
- Escape at 31993–32000 frees the map data, sets EAX=0 and jumps to the common epilogue.
- Enter at 32001–32030 calls can_i_play_this_city for data_55030; it proceeds only if AL equals 1. Then it looks up a value from data_5b071, records selected country in data_60b36, writes the level value into EXPORT_SYMBOL(current_levno), frees map resources and returns EAX=9.
- The left-click mission-start zone at 32041–32075 performs the same eligibility check and current_levno update before returning EAX=9. The zone is a strict coordinate interval and should not be treated as generic map clicking.
- A separate left-click back zone at 32076–32094 frees map resources and returns EAX=0.
- Other clicks and tax adjustment actions loop back to map selection; they do not directly establish a return value of 10.
- The parent select() caller at 54616–54627 checks 9 and 10 and calls load_text(current_levno, brief_text) for either. That is a confirmed parent-side branch, NOT evidence of a map_selection path which returns 10. No direct EAX=10 return was identified in the inspected complete map_selection body (31709–32154). The previous Audit 4.7's characterisation of 10 as an existing map-selection-derived transition is too strong: the caller accommodates 10, but production from the callee is unverified.
- The exact mission-file semantics of data_5b071 and the load_text resource format require separate source inspection.

## Mission Builder implications
A selectable custom campaign cannot reuse return 9 as a generic mode identifier; 9 already represents an eligible territory mission selection with current_levno prepared. Do not assume 10 is an available custom mode identifier merely because the parent tests it. Preserve the validated city selection and briefing load for original campaigns. Campaign identity and persistence status must be distinct from map-selection return values.
