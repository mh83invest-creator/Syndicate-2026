## Assembly evidence
Source inspected: engine/src/syndre.sx, blob c35e22621a93d1e07c44d40de8867446ff7c64bf.

- Literal call-site enumeration of the assembly text located one direct 'call LoadSaveGame' at line 54631, in the main select() dispatch handler func_37b93.
- That handler stores the EAX return value to 0x4(%esp) at 54632 then jumps to def_378BB at 54633.
- The parent selection routine uses 0x4(%esp) as a menu state/selection value: lines 54672-54685 compare it to 10, 6 and the previous state, and may invoke show_opt; lines 54710-54711 continue looping unless selection state equals 10. The exact semantics of all state values and visual feedback require deeper analysis.
- LoadSaveGame at 30714 loads EBP into EAX immediately before return. Cancellation handler at 30614-30618 clears EBP before exiting; load handler at 30621-30631 sets its menu exit flag without checking ac_load_player and subsequently clears EBP at jump_272a6 (30648-30649); save handler at 30634-30646 likewise ignores ac_save_player status and reaches the same EBP clear. Therefore these inspected cases return zero as parent selection value regardless of file-operation outcome. The return value is not a success/failure result for save/load.
- Literal assembly calls found for native save functions: ac_load_save_text at 30397 and 54577; ac_load_player at 30627; ac_save_player at 30643. These are direct calls in this assembly file only; not an exhaustive repository-wide indirect or native-caller inventory.
- The save/load UI has its own dispatch table at 30337-30350, with 0..9 selecting slots, index 10 cancellation, index 11 load and index 12 save. This table is distinct from main select() dispatch at 54133-54145.

## Boundary for Mission Builder
A new campaign-mode selection and save silo must not infer 'success' from the legacy LoadSaveGame return value. The parent selection variable determines menu navigation, while the save routines presently expose insufficient status. Any future implementation needs distinct operation outcomes, a mode-aware slot namespace, validated reads/writes, and protected compatibility for Original Campaign, American Revolt, World Domination and per-custom-campaign saves. Preserve the original ten-slot interface unless separately approved.
