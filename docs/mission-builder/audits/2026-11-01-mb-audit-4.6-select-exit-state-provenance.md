## Verified control-flow evidence
1. select() begins at assembly lines 54149–54159. After saving four registers, reserving 16 local bytes and temporarily pushing the load-files pointer, 'xor %ah,%ah; mov %ah,0x10(%esp)' zero-initializes the local byte which is subsequently 0xc(%esp) when the pushed argument has been removed at 54165. This is the default select() return byte.
2. The source has a single direct write of 1 to this byte: 'movb $0x1,0xc(%esp)' at line 54715, following 'cmpl $0x6,0x4(%esp)' / 'jne jump_37c42' at 54713–54714. The return byte is subsequently read at line 54720 for menu ending behavior, then loaded into AL at 54851 just before return.
3. In the main menu loop at 54375–54385, '0x4(%esp)' represents a menu state. Comparing state 6 leads directly to jump_37c36 (54376–54377); F10 key input (lbKeyOn+0x44) sets that same state to 6 at 54382–54385. Both reach the conditional return-byte setting at 54713–54715.
4. A distinct menu state 10 is compared at 54369–54372 and 54710–54711. It goes to jump_37c36 / cleanup without requiring state 6; its non-6 return byte remains zero on the inspected path. State 10 must not be silently treated as Exit or an operation-success code.
5. Mainline syndicate() tests the returned AL at lines 206–209: nonzero branches to jump_1033f and returns at 300–303; zero falls through to mission initialization. See MB-AUDIT-4.5.
6. The separate LoadSaveGame return is stored to 0x4(%esp) at 54631–54633, not to the select() return byte. Thus file-operation success cannot be inferred from AL on exit from select().

## Boundaries and risks
The existing menu state 6 is reserved by source behavior for exiting the game flow; it is unsafe to repurpose this existing value for World Domination or Custom Campaign. A future mode-selection design must keep navigation/exit, campaign identity and persistence outcome as independent concepts. Existing Original Campaign, American Revolt, save slots, successful-save credits behavior and protected v0.7 must remain unchanged.

## Verification
Evidence is a complete-blob search for the literal 0xc(%esp) accesses in the select() assembly region and direct examination of entry, F10, state 6/10 and return branches. Inline/aliased writes, alternate compiler variants and runtime effects have not been tested; no claim is made about all indirect modifications to this stack slot. Not performed: Windows build, gameplay/UI tests, file writes or code changes.
