## Verified direct call graph
- One literal 'call select' appears in the inspected assembly at line 206, in exported syndicate() at lines 199–209. Its AL return is tested immediately: if nonzero, branch to jump_1033f; if zero, continue through reset_mission_info and initialise_player.
- Following the zero-return path, syndicate() tests game state and invokes the single-player/multiplayer processing loop (roughly lines 211–279). The tactical loop calls gameplay functions including scroll_map, draw_mapwho, draw_panel and ac_game_update. This is a concrete menu-to-gameplay integration boundary.
- Once that processing loop exits, the code invokes free_map_level at line 285; a keyboard branch at 286–287 can return to the select() loop.
- One direct 'call LoadSaveGame' appears at assembly line 54631 inside the select() handler func_37b93; EAX is assigned to 0x4(%esp) at 54632. See MB-AUDIT-4.3.
- Literal direct calls to ac_load_player and ac_save_player in the same assembly are at lines 30627 and 30643, both inside LoadSaveGame. Direct ac_load_save_text calls at 30397 and 54577.
- This is a literal-direct-call inventory for this source blob; indirect function-pointer calls, alternative C entry points, and external launching paths are NOT comprehensively ruled out.

## Engineering implications
- select() is a game loop gate. A future mode selector (Original Campaign / American Revolt / World Domination / Custom Campaign) must have an explicit, tested separation between the menu/selection result and persistence operation result, before starting the appropriate game state.
- The current zero/nonzero AL branch in syndicate() is a flow decision, NOT a save success indication. Save and load errors are not represented in the existing LoadSaveGame return (per MB-AUDIT-4.2 and 4.3).
- Campaign-specific save namespaces must be selected before enumeration and file access, and must never silently overwrite Original Campaign slots or reinterpret existing 28247-byte records.
- Preserve protected v0.7, 16 FPS mission simulation, menu speed, classic campaigns, and the parallel mainline work. No implementation is approved by this audit.
