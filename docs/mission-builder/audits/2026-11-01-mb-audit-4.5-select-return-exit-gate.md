## Verified control flow
1. syndicate() at assembly lines 199–209 invokes select at line 206 and tests AL immediately. A nonzero return branches to jump_1033f at line 300, which restores registers and returns at lines 301–303. A zero return continues through reset_mission_info and initialise_player into game-state conditional processing. The zero return therefore means 'do not take the early exit branch'; it is not a confirmed save/load success signal.
2. Following gameplay the routine calls free_map_level at 285. It can loop back to select (286–287), and its later post-mission path invokes transfer_people_into_player and level_finished at 295–297 before another possible select loop at 298–299.
3. select() cleanup at lines 54838–54857 frees UI assets and any loaded audio bank resources, restores DrawFlags from OldDrawFlags, then at line 54851 loads the byte from 0xc(%esp) into AL and returns at 54857. This is the return byte consumed by syndicate's line-207 test. Thus the early exit gate is tied to a specific select-local byte, not directly to the selection index stored in 0x4(%esp).
4. The parent menu save/load handler func_37b93 at 54630–54633 invokes LoadSaveGame and stores its EAX as the menu's 0x4(%esp) state. Previous audits 4.1–4.3 establish that normal cancel/save/load handlers return zero independently of file operation outcome. Do not conflate this menu state with select's eventual return byte at 0xc(%esp).
5. A select() branch at 54713–54715 sets 0xc(%esp)=1 if menu state equals 6, but because the preceding control-flow labels and conditions involve branch reuse, this alone does not establish every possible route that sets the return byte. Full input-state/state-machine mapping remains open.

## Integration consequence
Original Campaign, American Revolt, World Domination and Custom Campaign selection must be introduced without repurposing AL as a save operation success flag. A later implementation must explicitly separate (a) menu navigation/game exit decision, (b) selected campaign identity and (c) save/load operation outcome. Preserve v0.7 and current 16 FPS simulation, and treat old saves as immutable during audits.
