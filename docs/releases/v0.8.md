## Requirement
Add a camera edge-scroll speed control accessible in options, adjustable from slow to fast, retaining **exact v0.7 speed as default**, persisting between sessions. No effect on agent movement, simulation timing, sound, or 30 FPS menu pacing. Preserve four-direction and corner scrolling.

## Architecture gates
1. Inspect `engine/src/syndre.sx` around `scroll_map` and callers to determine whether movement uses steps, delay or separate positional increments. Preserve the confirmed camera edge-coordinate normalization.
2. Identify existing in-game options menu and input controls. If the engine does not have a safe reusable slider, implement a self-contained options UI instead of misrepresenting a hidden configuration value as a slider.
3. Persist setting to user-writable local directory; validate or clamp its values; fallback to v0.7 on missing/corrupt preferences.
4. Avoid globally changing `game_update_full` frame rate; mission loop stays at 16 FPS and only the three v0.7 strategic screens use 30 FPS.
5. Add compile-time assertions / runtime tests for default and limits; perform native Windows DLL import check and actual gameplay regression test.
