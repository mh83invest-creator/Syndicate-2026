## Approved staged scope and acceptance criteria

### v0.9A — Presentation
- Improve the title screen, main menus, strategic screens and mission briefing presentation and UI styling.
- Inspect the actual rendering paths, palettes, artwork provenance, input hitboxes and relevant UI code before edits. Maintain existing navigation, resolution support and functional input regions.
- Prefer isolated presentation changes with clear before/after captures and paths. No new gameplay, audio, timing or camera behavior.
- Require native i686 build and Windows visual/menu checks, including navigation to and from all affected screens.

### v0.9B — Atmospheric lighting
- Add distinctly night-time missions with readable street lighting, vehicle headlights, lit windows and neon signs; use per-mission/environment conditions rather than darkening every map indiscriminately.
- Audit renderer, map graphics, sprites, palette, overlays, depth/occlusion, performance, and data-loading paths first. Do not assume dynamic lighting is supported.
- Lighting must be visible in actual game frames, respect map/object placement and mission readability, and not alter AI/visibility/gameplay or mission timing.
- Verify day/night presentation, lights and visuals against screenshots and Windows mission playtests. Preserve all existing effects and sound. Don't claim these features until demonstrated.

### v0.9C — Consolidated showcase
- Integrate only accepted/tested v0.9A and v0.9B changes; produce Windows i686 build and packaged test instructions with correct native DLLs.
- Verify native MinGW32 dependencies (SDL2, OpenAL, WildMIDI), reject MSYS audio DLL imports, check artifact integrity and game startup with legally supplied retail data.
- Separate CI compilation success from Windows gameplay verification. Test menus, briefings, day/night missions, scrolling (four directions/corners/top edge), focus/alt-tab, music/sound, timing, mission start/end, and rendering under load.
- Publish release handover/changelog, test evidence, known issues, rollback instructions and packaged artifact reference. Do not merge to main before explicit user acceptance.
