## Actual new source files
- `engine/bflibrary/tests/eg_environment_face.h`: public test-only expander interface and dimensions.
- `engine/bflibrary/tests/eg_environment_face.c`: decodes 320-byte 32×16 candidate environment component into four indexed colour bitplanes and one **uninterpreted** mask bitplane. Runs edge-aware 2× scaling twice to 128×64 output; colours selected through explicit supplied 16-entry RGBA palette. Keeps raw mask bits as separate 4× nearest-neighbour output so alpha/occlusion are **not guessed**.
- `engine/bflibrary/tests/eg_environment_face_test.c`: synthetic tests of incorrect argument rejection; full bounds and canary preservation; exact raw mask reproduction and 16-index palette behaviour; deterministic image output on patterned data.
- `.github/workflows/graphics-sdl2-validation.yml`: compiles/tests these files using existing Windows/MSYS2 jobs. Existing original scaler and engine build steps are retained unchanged.

## Integration contract
**No in-game integration yet.** The original four-plane environment compositor has not been shown to accept 128×64 RGBA faces, and the exact mask meaning is not yet independently established. Do not simply overwrite source 320-byte component records or route new RGBA pixels into the existing indexed/planar buffers. Do not assume `map01.dat` is mission one. High-resolution enhancement requires a separate verified insertion mechanism and draw-order/occlusion design; this experimental component is a safe preparation layer, not a rendering replacement.
