## Verified source observations
Source: engine/src/syndre.sx, blob c35e22621a93d1e07c44d40de8867446ff7c64bf.
- In map_selection, the Enter path (32001-32030) and mission-start click path (32049-32075) check can_i_play_this_city before choosing a level.
- Both paths use the selected country index with a 19-byte stride to read a level byte from the embedded map descriptor at data_5b071, update current_levno and data_60b36, free map resources, and return 9.
- data_5b071 is a label within the map_countries embedded data area (84528-84545), not a separately proven level table.
- Parent select() at 54616-54627 loads briefing text for map return 9 or 10. Return 10 is handled by the caller but not established as a direct map_selection return.
- load_text (55249-55289) constructs a language-dependent filename, calls LbFileReadRNC, obtains LbFileLengthRnc and places a trailing terminator at the returned length. This block does not explicitly inspect file-load or length errors before the terminator operation. The precise storage capacity and runtime consequences require examination.
- The common C source engine/bflibrary/src/general/gfile.c provides LbFileLengthRnc and LbFileLoadAt. The assembly reference LbFileReadRNC needs a separate linkage investigation; do not presume it is an alias.
