## Verified repository inventory
Queried the complete recursive Git tree of feature/mission-builder-audit using GitHub API. Response reported truncated=false and 431 tree entries. No paths matched mission briefing file patterns missNN.dat, RNC files, or data-directory mission assets.
The branch README explicitly states that proprietary retail Syndicate game data is not committed. The Mission Builder handover likewise records that original game assets must be supplied separately.
These facts establish absence of inspectable retail briefing resources in this repository tree, not absence from users' installed games or other private sources.

## Consequence for RNC/Huffman audit
Audit 5.6 found that the C reference decoder allocates 32 entries and reads a five-bit symbol count, while the legacy assembly decoder uses 16 bytes of temporary symbol-length storage and 128-byte destination tables. There is no basis in the repository alone to claim actual retail mission briefings use symbol counts above 16, or that real assets trigger a fault.
This is an asset-availability gate, not a failed test or a reason to patch functioning gameplay prematurely.
