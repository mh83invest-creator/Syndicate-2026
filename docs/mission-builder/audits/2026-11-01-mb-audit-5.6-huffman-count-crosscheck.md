## Inspected sources
- engine/bflibrary/src/general/rnc_1fm.c (Mission Builder branch): huf_table definition and read_huftable at lines 84–121.
- engine/src/syndre.sx, blob c35e22621a93d1e07c44d40de8867446ff7c64bf: assembly make_huftable and static table allocations, as examined in Audits 5.3–5.5.

## Findings
1. The C decoder's read_huftable reads a count with bit_read(...,0x1F,5,...), supporting encoded values 0–31. It allocates int leaflen[32] and stores up to 31 4-bit code lengths. The huf_table also has table[32]. This is stronger evidence than simply interpreting the 5-bit field: the C implementation deliberately sizes both arrays above 16.
2. The C code computes leafmax from the 4-bit lengths and loops over each length and symbol, inserting matching entries into h->table. Entries with code length zero are not inserted. For a 31-symbol input, the declared C destination allocation can accommodate every nonzero length (at most 31 entries).
3. The assembly helper reads the same 5-bit count but has a 16-byte stack scratch region, and its three Huffman destination tables each reserve 128 bytes. Audit 5.5 established that the 17th matching entry writes past the end of a 128-byte table under the modeled assembly pointer progression; a count of 17 also exceeds 16 scratch bytes.
4. This cross-check defeats any assumption that the RNC format's allowable symbol-count field is inherently capped at 16. It does NOT prove that shipped Syndicate compressed assets use 17+ symbols, or that a malformed example was run. No retail asset contents were inspected.
5. The C and assembly decoders remain distinct calling conventions and storage designs. Do not hot-swap implementations without an ABI and compatibility review.

## Test and decision gate
- Examine authentic mission-text RNC headers and bitstream table counts across languages and campaign assets to determine real-world maximum, using copies only.
- In disposable test builds, exercise 16, 17, and 31 symbol counts and verify both source and destination extents under instrumentation.
- Define a bounded decoding contract before accepting externally authored campaign/briefing data.
- Coordinate changes with mainline RNC auditing; protect v0.7, existing saves, Original Campaign, American Revolt and gameplay timing.
