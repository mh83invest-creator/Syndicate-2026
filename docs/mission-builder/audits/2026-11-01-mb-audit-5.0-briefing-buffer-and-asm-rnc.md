## Confirmed source evidence
Source: engine/src/syndre.sx, blob c35e22621a93d1e07c44d40de8867446ff7c64bf.

1. String definitions at lines 82522–82525: language-zero format is `data/miss%02.2d.dat`; alternate format is `data/miss%01d%02.2d.dat` (language digit followed by two-digit mission ID). `load_text` uses language to choose the format at lines 55255–55275.
2. `brief_text` is declared at lines 85610–85611 with `.fill 0xfa0`, i.e. 4000 allocated bytes. Thus a null-terminated payload filling that region completely needs explicit capacity enforcement.
3. `load_text` at 55249–55289 first sets the beginning of the destination to NUL, formats a mission filename, then invokes `LbFileReadRNC` followed by `LbFileLengthRnc`, finally placing a terminator at destination plus the reported file length (55277–55286). It does not explicitly validate either operation's result or the destination capacity.
4. Contrary to the unresolved-linkage question in Audit 4.9, `LbFileReadRNC` **is defined in the assembly**, at lines 14916–14960. Its flow opens the file (`LbFileOpen_`), calls `LbFileLengthRnc`, reads using `LbFileRead_`, calls `UnpackM1`, optionally reports a decompression error, then closes the handle. Its return value at line 14955 is the saved handle (`ESI`), not the bytes read or decoded byte count. The format and return behavior must be treated distinctly from the C `LbFileLoadAt` implementation.
5. The assembly loader passes the destination buffer twice to `UnpackM1` and does not check the `LbFileRead_` byte count in the inspected block. No runtime malformed-file test has been performed. Source-level input/bounds risk exists but specific effects on normal assets are unverified.

## Development consequences
Custom mission briefing support needs an explicit, mode-aware file naming and size contract; do not assume arbitrary IDs fit the original two-digit filename pattern or the embedded one-byte level ID. Safely separate input file size, unpacked length, destination capacity, and status before future implementation. Preserve original retail resources, Original Campaign, American Revolt, v0.7 and existing save namespaces.

## Next audit
Examine the assembly `LbFileLengthRnc` and `UnpackM1` implementation details and the actual byte-count behavior of `LbFileRead_` on short reads, comparing them with the mainline RNC audit. Prepare an implementation/test gate only after shared engineering coordination.
